Defining the Machine Learning Models

The experiment compares five regression algorithms:

  • RF- Random Forest

  • GBR- Gradient Boosting

  • DT - Decision Tree

  • KNN - K-Nearest Neighbors

  • XGB- XGBoost .

Decision Tree (DT)

Theoretical Background

A Decision Tree is a non-parametric supervised learning algorithm that partitions the feature space into mutually exclusive rectangular regions through a sequence of recursive binary splits. The algorithm evaluates feature thresholds to maximize variance reduction for continuous numerical targets. In the context of forecasting the number of foreign tourists, the model traverses down the tree branches based on specific feature conditions (e.g., geographical proximity, economic indicators) until it reaches a terminal node (leaf), where the predicted numerical value is calculated as the mean of the training samples residing in that leaf.

Documentation Link: sklearn.tree.DecisionTreeRegressor

Key Parameters & Configuration

  • max_depth=10: Restricts the maximum number of sequential splits allowed, acting as regularization to prevent overfitting.

  • min_samples_leaf=5: Specifies the minimum number of observations required to form a terminal leaf node, ensuring the numerical prediction is statistically robust and not biased by outliers.

  • random_state=SEED: Fixes the pseudo-random number generator seed to ensure reproducibility.

Random Forest (RF)

Theoretical Background

Random Forest is an ensemble learning method based on bagging combined with randomized feature selection. It constructs a multitude (\(N = \text{n\_estimators}\)) of independent decision trees during training. For forecasting the numerical volume of foreign tourists, the final predicted value is derived by aggregating the numerical predictions (via arithmetic mean) across all individual decision trees, significantly reducing variance and mitigating the risk of overfitting.

Documentation Link: sklearn.ensemble.RandomForestRegressor

Key Parameters & Configuration

  • n_estimators=100: Defines the total number of independent decision trees constructed within the ensemble.

  • max_depth=10 & min_samples_leaf=5: Control the structural complexity and regularization constraints of each constituent tree.

  • n_jobs=-1: Utilizes all available CPU cores for parallel processing.

Gradient Boosting Regressor (GBR)

Theoretical Background

Gradient Boosting is an additive ensemble technique that builds models sequentially. Instead of bagging, it employs boosting, where each new weak learner is trained to predict the residual errors (the differences between actual and predicted numerical tourist numbers) made by the preceding ensemble. By optimizing a differentiable loss function iteratively, the model progressively minimizes numerical prediction error across successive optimization steps.

Documentation Link: sklearn.ensemble.GradientBoostingRegressor

Key Parameters & Configuration

  • n_estimators=100: Specifies the total number of sequential boosting iterations.

  • max_depth=5: Controls the depth of each sequential tree.

  • learning_rate=0.1: Acts as a shrinkage factor scaling the contribution of each tree to the numerical forecast.

K-Nearest Neighbors Regressor (KNN)

Theoretical Background

K-Nearest Neighbors is a non-parametric, instance-based learning algorithm. To forecast the exact number of tourists from a specific country, the algorithm calculates the distance (e.g., Euclidean distance) between the target instance and all points in the feature space, identifies the \(K\) closest training samples, and computes a distance-weighted average of their numerical target values.

Documentation Link: sklearn.neighbors.KNeighborsRegressor

Key Parameters & Configuration

  • n_neighbors=5: Defines the neighborhood size (\(K\)) used to gather similar historical observations.

  • weights=“distance”: Ensures that closer geographic or economic neighbors exert a stronger numerical influence on the final forecasted count.

  • n_jobs=-1: Parallelizes distance-matrix calculations across all CPU cores.

XGBoost (eXtreme Gradient Boosting - XGB)

Theoretical Background

XGBoost is an advanced, highly optimized implementation of gradient-boosted decision trees designed for regression tasks. It formally integrates regularized objective functions and second-order Taylor expansion approximations of the loss function, allowing for high-precision numerical forecasting of foreign tourist counts while controlling model complexity and preventing overfitting.

Documentation Link: xgboost.XGBRegressor

Key Parameters & Configuration

  • n_estimators=100: Specifies the total number of sequential gradient-boosted trees built.

  • max_depth=6: Determines the maximum allowable depth for each individual boosted tree.

  • learning_rate=0.1: The shrinkage step-size used to scale the impact of each new tree on the final prediction.

  • verbosity=0: Suppresses internal runtime logs during execution.

for country_name, df_temp in country_dfs_2019_2020.items():

    print("\n")
    print("#" * 100)
    print(f"KRAJ: {country_name}")
    print("#" * 100)

    # --------------------------------------------------------
    # CECHY DLA DANEGO KRAJU
    # --------------------------------------------------------

    features_country = country_features[

    ]

    print(
        f"Liczba cech: {len(features_country)}"
    )

    print(
        "Cechy:",
        features_country
    )

    # --------------------------------------------------------
    # USUWAMY WIERSZE BEZ D8R1
    # --------------------------------------------------------

    df_temp = df_temp[
        df_temp[TARGET].notna()
    ].copy()

    # ========================================================
    # PĘTLA PO MISS
    # ========================================================

    for miss_col in MISS_COLS:

        print("\n")
        print("-" * 100)
        print(f"{country_name} | {miss_col}")
        print("-" * 100)

        # ----------------------------------------------------
        # MASKA TESTOWA
        # ----------------------------------------------------

        test_mask = df_temp[
            miss_col
        ].isna()

        train_mask = ~test_mask

        print(
            "TEST wg maski:",
            int(test_mask.sum())
        )

        print(
            "TRAIN wg maski:",
            int(train_mask.sum())
        )

        # ----------------------------------------------------
        # TRAIN / TEST
        # ----------------------------------------------------

        train = df_temp.loc[
            train_mask
        ].copy()

        test = df_temp.loc[
            test_mask
        ].copy()

        # ----------------------------------------------------
        # USUWAMY WIERSZE Z BRAKAMI W CECHACH
        #
        # Nie imputujemy.
        # ----------------------------------------------------

        train_complete = train.dropna(
            subset=features_country
        ).copy()

        test_complete = test.dropna(
            subset=features_country
        ).copy()

        print(
            "TRAIN po sprawdzeniu cech:",
            len(train_complete)
        )

        print(
            "TEST po sprawdzeniu cech:",
            len(test_complete)
        )

        if len(train_complete) == 0:

            print(
                "!!! BRAK TRAIN - POMIJAM !!!"
            )

            continue

        if len(test_complete) == 0:

            print(
                "!!! BRAK TEST - POMIJAM !!!"
            )

            continue

        # ----------------------------------------------------
        # X / y
        # ----------------------------------------------------

        X_train = train_complete[
            features_country
        ]

        y_train = train_complete[
            TARGET
        ]

        X_test = test_complete[
            features_country
        ]

        y_test = test_complete[
            TARGET
        ]

        # ====================================================
        # MODELE
        # ====================================================

        for model_name, model_template in MODELS.items():

            print(
                f"\n  Model: {model_name}",
                end=" | "
            )

            try:

                # ------------------------------------------------
                # CLONE MODELU
                # ------------------------------------------------

                model = clone(
                    model_template
                )

                # ------------------------------------------------
                # TRAIN
                # ------------------------------------------------

                model.fit(
                    X_train,
                    y_train
                )

                # ------------------------------------------------
                # PREDYKCJA
                # ------------------------------------------------

                y_pred = model.predict(
                    X_test
                )

                # ------------------------------------------------
                # METRYKI
                # ------------------------------------------------

                rmse = np.sqrt(
                    mean_squared_error(
                        y_test,
                        y_pred
                    )
                )

                mae = mean_absolute_error(
                    y_test,
                    y_pred
                )

                d8r1_sum_real = (
                    y_test.sum()
                )

                d8r1_sum_pred = (
                    y_pred.sum()
                )

                if d8r1_sum_real != 0:

                    bias_pct = (
                        (
                            d8r1_sum_pred
                            -
                            d8r1_sum_real
                        )
                        /
                        d8r1_sum_real
                    ) * 100

                else:

                    bias_pct = np.nan

                # ------------------------------------------------
                # MAPE
                # ------------------------------------------------

                non_zero_mask = (
                    y_test != 0
                )

                if non_zero_mask.sum() > 0:

                    y_test_nz = y_test[
                        non_zero_mask
                    ]

                    y_pred_nz = y_pred[
                        non_zero_mask.values
                    ]

                    mape = (
                        np.mean(
                            np.abs(
                                (
                                    y_test_nz.values
                                    -
                                    y_pred_nz
                                )
                                /
                                y_test_nz.values
                            )
                        )
                        * 100
                    )

                else:

                    mape = np.nan

                # WYNIK OGÓLNY

                    ),

                    "D8R1_sum_real": (
                        d8r1_sum_real
                    ),

                    "D8R1_sum_pred": (
                        d8r1_sum_pred
                    ),

                    "RMSE": rmse,

                    "MAE": mae,

                    "MAPE": mape,

                    "Bias_pct": bias_pct

                })

                # PREDYKCJE MIESIĘCZNE
                # =================================================
                #
                # Zachowujemy każdą obserwację testową.
