Simulation of Missing Data

The synthetic dataset used in this analysis does not initially contain any missing values. To simulate missing data for foreign tourist counts, three additional variables are created separately for each of the five selected countries:

  • miss_10 – 10% of foreign tourist count observations are randomly set as missing.

  • miss_20 – 20% of foreign tourist count observations are randomly set as missing.

  • miss_30 – 30% of foreign tourist count observations are randomly set as missing.

Missing values are generated using the MCAR (Missing Completely At Random) mechanism, meaning that the probability of an observation being missing does not depend on its observed or unobserved values.

The missingness is generated using a nested structure. This means that all observations missing in miss_10 are also missing in miss_20, and all observations missing in miss_20 are also missing in miss_30:

\[ miss\_10 ⊂ miss\_20 ⊂ miss\_30 \]

This approach provides a more realistic simulation of increasing levels of missing data. In practice, as the reporting deadline approaches and more reports become available, the amount of missing information decreases. The nested structure therefore allows the models to be evaluated under progressively different levels of data availability while keeping the underlying observations comparable across scenarios.

The new variable provides a more readable country identifier and is used in subsequent steps to:

Defining the MCAR Simulation Parameters

This step defines the parameters used to simulate missing data.

The original target variable is D8R1, representing the number of foreign tourists. This variable remains unchanged throughout the simulation and serves as the reference value for evaluating the performance of the imputation models.

Three missing-data scenarios are defined:

  • miss_10 – 10% of observations are simulated as missing,

  • miss_20 – 20% of observations are simulated as missing,

  • miss_30 – 30% of observations are simulated as missing.

The missing values are generated according to the MCAR (Missing Completely At Random) mechanism. This means that the probability of an observation being selected as missing does not depend on its value or on any other observed characteristics.

A fixed random seed, 42, is used to initialise the random number generator. This ensures that the same observations are selected as missing every time the code is executed, making the simulation reproducible.

Importantly, the missingness scenarios are generated using a nested structure. The observations missing in the 10% scenario are also missing in the 20% scenario, while the 20% missing observations are included in the 30% scenario.

This allows the three scenarios to represent progressively increasing levels of missing information while maintaining comparability between them.

Code 
target = 'D8R1'

missing_rates = {
    'miss_10': 0.10,
    'miss_20': 0.20,
    'miss_30': 0.30
}

# State random seed
rng = np.random.default_rng(42)
Code 
# Copy of data
df_missing=df.copy()
target = 'D8R1'

missing_rates = {
   'miss_10': 0.10,
   'miss_20': 0.20,
   'miss_30': 0.30
}

# kopia oryginalnego targetu
df_missing['miss_10'] = df_missing[target]
df_missing['miss_20'] = df_missing[target]
df_missing['miss_30'] = df_missing[target]

# generator losowy
rng = np.random.default_rng(42)

# każdy KKR osobno
for kkr in selected_kkr:

   # indeksy obserwacji danego kraju
   idx = df_missing.index[
       df_missing['KKR'] == kkr
   ]

   n = len(idx)

   if n == 0:
       continue

   # jedno losowanie kolejności obserwacji
   shuffled_idx = rng.permutation(idx)

   # liczba braków
   n_10 = int(round(n * 0.10))
   n_20 = int(round(n * 0.20))
   n_30 = int(round(n * 0.30))

   # NESTED:
   # 10% znajduje się w pierwszych 10%
   # 20% zawiera te same 10% + kolejne 10%
   # 30% zawiera te same 20% + kolejne 10%

   missing_10_idx = shuffled_idx[:n_10]
   missing_20_idx = shuffled_idx[:n_20]
   missing_30_idx = shuffled_idx[:n_30]

   # wprowadzenie braków
   df_missing.loc[
       missing_10_idx,
       'miss_10'
   ] = np.nan

   df_missing.loc[
       missing_20_idx,
       'miss_20'
   ] = np.nan

   df_missing.loc[
       missing_30_idx,
       'miss_30'
   ] = np.nan

Creating Nested MCAR Missing-Data Scenarios

This step introduces the simulated missing values into the dataset separately for each of the five selected countries.

First, three new variables — miss_10, miss_20, and miss_30 — are created as copies of the original target variable, D8R1. The original D8R1 values are therefore preserved and can later be used as the ground truth for evaluating the imputation results.

The simulation is performed independently for each KKR (country). For each country, the observations are randomly shuffled using the fixed random-number generator defined previously. The number of observations to be treated as missing is then calculated as 10%, 20%, and 30% of the total number of observations for that country.

The key feature of this procedure is the nested structure of the missingness. A single random ordering of observations is generated for each country, and progressively larger portions of this same ordering are selected:

  • miss_10 contains the first 10% of randomly selected observations,

  • miss_20 contains the same 10% plus an additional 10%,

  • miss_30 contains the same 20% plus an additional 10%.

The selected observations are then replaced with NaN in the corresponding variables.

This nested design ensures that the three scenarios differ only in the amount of missing information, while the missing observations from the less severe scenario remain part of the more severe scenarios. This makes the comparison of model performance across 10%, 20%, and 30% missingness more consistent and realistic.

The original D8R1 variable is not modified, which allows the simulated missing values to be compared with the true observed values during the later evaluation of the imputation models.

print("\n\n")

       df_missing['KKR'] == kkr

Verifying the Nested Missing-Data Structure

This step verifies that the simulated missing values follow the intended nested structure for each selected country.

For each country, the code identifies which observations are missing in miss_10, miss_20, and miss_30. It then checks two conditions:

  • whether every observation missing in miss_10 is also missing in miss_20,

  • whether every observation missing in miss_20 is also missing in miss_30.

The logical conditions verify that:

miss_10 ⊂ miss_20 ⊂ miss_30

A result of True confirms that the nested structure has been correctly implemented.

This validation is performed separately for each country, ensuring that the missing-data simulation is correctly constructed across all five selected countries before the datasets are used in further analysis.

The check is particularly important because the nested structure guarantees that increasing missing-data scenarios are comparable: the 20% scenario extends the 10% scenario, while the 30% scenario extends the 20% scenario, rather than introducing three completely independent sets of missing observations.

Creating the Five Final Country-Specific Datasets

In this final data preparation step, five country-specific datasets are created, with one Excel file produced for each selected country.

For each KKR, the code first filters the complete dataset to retain only observations belonging to that country. It then retrieves the country-specific set of features previously selected by the Elastic Net procedure.

Each final dataset contains:

  • identification variables: REGON, OKRES, KKR, country_en, and data,

  • the original target variable D8R1, which remains unchanged and serves as the reference value,

  • the three simulated missing-data scenarios: miss_10, miss_20, and miss_30,

  • only the explanatory variables selected specifically for that country.

Any duplicate columns are removed before the final dataset is created.

The resulting datasets are stored in the final_datasets dictionary and saved as separate Excel files:

Germany.xlsx Italy.xlsx Ukraine.xlsx United Kingdom.xlsx United States.xlsx

This structure provides one complete modelling dataset per country, containing all three nested missing-data scenarios alongside the original target and the country-specific selected predictors. It also ensures that unnecessary variables are excluded from the final repository datasets, making them ready for the subsequent imputation and machine-learning stages.
